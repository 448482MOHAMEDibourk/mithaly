Context — ملفات السياق المعماري
=============================

هذا المجلد يخزن ملفات السياق (architecture context, decision records, environment descriptions) التي تستخدمها الطبقات والمولد لفهم بيئة التشغيل.

محتويات مقترحة:
- `architecture.md` — وصف معماري للمشروع.
- `environment.md` — وصف بيئة التشغيل المطلوبة.
