Mithaly Knowledge Reference — الأنماط والسياق
===========================================

الهدف
-----
هذا المجلد هو المرجع المركزي للمعرفة في مشروع Mithaly. يحوي الأنماط المعمارية، سياق النظام، قواعد وسياسات التشغيل، ونماذج استخدام متكررة تساعد المولد والطبقات على العمل بتناسق.

مقترح بنية المجلد
------------------
- `patterns/` — قوالب ونماذج تصميم (على مستوى الـ architecture وmodules)
- `policies/` — سياسات التشغيل والحوكمة (أمان، موارد، متطلبات بيئة)
- `context/` — ملفات سياق معماري ونماذج بيانات
- `examples/` — أمثلة مدخلة/مخرجات لنماذج التوليد

كيفية الاستخدام
----------------
- المولد (`project-generator`) يمكنه قراءة الأنماط والقوالب من هذا المجلد لتوليد مشاريع تتوافق مع سياسات وممارسات المؤسسة.
- الطبقات يمكنها الرجوع إلى `policies/` لاختبار العلاقات والقيود قبل التخطيط والتنفيذ.

ملاحظة
------
سأقوم لاحقًا بإضافة `patterns/`, `policies/`, و`examples/` إذا رغبت، وإدراج أمثلة عملية للاستخدام.
