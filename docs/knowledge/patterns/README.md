Patterns — قوالب التصميم والممارسات
=================================

هذا المجلد يحتوي على أنماط معمارية وممارسات تصميم موصى بها عند توليد مشاريع جديدة.

محتويات مقترحة:
- `service-templates.md` — أنماط لخدمات الويب (الواجهات، الخلفية، قواعد البيانات).
- `module-patterns.md` — تصميم الوحدات، الفصل، والاعتماد.
