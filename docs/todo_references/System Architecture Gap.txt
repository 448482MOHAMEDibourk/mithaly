🔹 المرحلة 1: المولد مستقل (Generator Acts Independently)
   المولد يحاول تشغيل Ollama بشكل افتراضي عبر OllamaClient
   البحث عن النماذج في المسار الدستوري: /var/lib/mithaly/models

🔹 المرحلة 2: نقطة الانعطاف (INFLECTION_POINT)
   عند فشل العثور على النماذج أو الاتصال بـ Ollama:
   - PolicyEnforcer يكتشف الفشل
   - يفعّل inflection_point=True في constraints
   - يسجل transition عبر TransitionLogger
   - يوقف التنفيذ الآلي

🔹 المرحلة 3: تدخل الطبقات الإدارية (Layer Intervention)
   الطبقة الإدارية تراجع الدستور وتقرر:
   
   ✓ الخيار 1: pull تلقائي (إذا كان مسموحاً حسب السياسات)
     → SafeExecutor يقوم بـ `ollama pull <model>`
     → يعود التنفيذ للمسار الطبيعي
   
   ✓ الخيار 2: طلب توضيح هيكلي (إذا كان حساساً)
     → إيقاف التنفيذ وطلب تدخل المستخدم
     → حفظ snapshot في docs/context/
     → إنشاء clarification_questions للمستخدم

🔹 المرحلة 4: استمرار أو إيقاف
   بناءً على قرار الطبقة الإدارية:
   - استمرار بعد حل الفجوة
   - OR إيقاف منظم مع توثيق السبب
