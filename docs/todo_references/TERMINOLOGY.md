# Terminology — Mithaly / مُعجم المصطلحات
======================================

هذا المستند هو المرجع الموحد للمصطلحات المستخدمة في مشروع Mithaly لضمان الاتساق بين المطورين والوكلاء الآليين.

## 1. فهرس دلالات المجلدات (Directory Semantics Index)

يوضح هذا الجدول الفرق بين المعنى العام للمجلد ومعناه الخاص داخل نظام Mithaly:

| المجلد | المعنى العام (General) | المعنى الخاص بـ Mithaly (Specific) |
| :--- | :--- | :--- |
| `docs/` | وثائق تقنية للقراءة | **مركز الإدارة (Control Center)**: المجلد الذي نتحاور منه وندير من خلاله دورة حياة النظام. |
| `docs/context/` | سياق عام أو خلفية | **الحالة التشغيلية (System State)**: يحتوي على اللقطات (Snapshots) والسجلات اللحظية التي تعكس وعي النظام الآن. |
| `docs/knowledge/` | معلومات عامة | **الذاكرة الدائمة (Long-term Memory)**: المستودع الذي يتم فيه "ترسيخ" الدروس المستفادة والأنماط الناجحة/الفاشلة. |
| `docs/rules/` | إرشادات للمطور | **النظام القانوني (Governance)**: الوثائق التي تحدد "كيف يجب أن يتصرف النظام" (الدستور، المصطلحات، المنهجية). |
| `docs/audit/` | مراجعة حسابات | **مختبر التحليل (Analysis Lab)**: تقارير نقدية متعمقة تهدف لاكتشاف الفجوات الهيكلية والتقنية. |
| `docs/archive/` | أرشفة ملفات قديمة | **السجل التاريخي (History Trace)**: ملفات أتمت مهمتها ولكنها تحفظ "أثر" تطور النظام. |
| `core/` | كود أساسي | **محرك التوليد (Generation Engine)**: القلب النابض الذي يحوي المولد (Generator) والمحرك (Engine). |
| `Raw_Artifact/` | مخرجات خام | **النفايات الكونية (Reference Junk)**: مشاريع فاشلة أو تجارب سابقة نعود إليها للعبرة فقط. |
| `MITHALY_CONSTITUTION.md` | دستور المشروع | **القانون الأعلى (The Law)**: مبادئ غير قابلة للتغيير تحكم سلوك الجميع. |
| `workflow.md` | مخطط العمل | **المخطط الهندسي (Blueprints)**: الوصف التقني الدقيق لحركة البيانات والعمليات. |
| `layered_flow.md` | تدقيق الطبقات | **المُفسّر (The Interpreter)**: الجسر الذي يربط القانون (الدستور) بالهندسة (الـ Workflow). |
| `knowledge.jsonl` | ملف سجل | **سجل الذاكرة (Memory Ledger)**: التاريخ الموثق لكل ما تعلمه النظام. |

## 2. الهيكلية المعمارية (Architectural Structure)

- **Layer / طبقة**: التقسيم الوظيفي الرئيسي (Gaps, Planning, Execution, Feedback). كل طبقة لها واجهة `process()` محددة.
- **Component / مكوّن**: وحدة برمجية داخل الطبقة (مثال: `GapAnalyzer`).
- **Module / موديول**: وحدة قابلة لإعادة الاستخدام في `src/mithaly/core` أو `modules`.
- **Specialist / أخصائي**: وحدة مسجلة في المحرك لتقديم مهمة تقنية محددة (مثال: `DebuggerSpecialist`).

## 2. المفاهيم السيادية (Sovereign Concepts)

- **Inflection Point / نقطة الانعطاف**: بوابة توقف إجبارية للمراجعة البشرية أو الإدارية عند اكتشاف مخاطر أو عدم وضوح.
- **Document Sanctity / قداسة الوثائق**: حماية الملفات الأساسية (مثل الدستور) من التعديل أو الحذف دون إذن صريح.
- **Sacred Files / الملفات المقدسة**: قائمة الملفات المحمية برمجياً بواسطة `PolicyEnforcer`.
- **Bridge Document / وثيقة الجسر**: مستند (مثل `layered_flow.md`) يربط بين المبادئ الدستورية والتفاصيل التقنية.

## 3. البيانات والمعرفة (Data & Knowledge)

- **Hybrid Memory / الذاكرة الهجينة**: نظام يجمع بين البحث المتجهي (ChromaDB) والسجل التسلسلي (JSONL).
- **Ledger / السجل**: ملف `knowledge.jsonl` الذي يوثق كل تجربة بنمط تسلسلي (Audit Trail).
- **Vector Store / المستودع المتجهي**: قاعدة بيانات ChromaDB للبحث الدلالي السريع.
- **Artifact / أثر**: مخرج ناتج عن العمل (كود، لقطة سياق، تذكرة تحليل).

## 4. الأدوات والتقنيات (Tools & Tech)

- **LangGraph**: الإطار البرمجي المستخدم لإدارة دورة حياة الوكيل (Workflow Orchestration).
- **MCP (Model Context Protocol)**: بروتوكول ربط الوكيل بالأدوات والموارد الخارجية.
- **RAG (Retrieval-Augmented Generation)**: تقنية تعزيز الردود بالمعرفة المسترجعة من الذاكرة.
- **Probe / مسبار**: حساس برمج في الطبقات يكتشف الاحتياجات التقنية (مثل الحاجة إلى قاعدة بيانات).

## 5. ملاحظات توجيهية
- يجب استخدام هذه المصطلحات في الـ `docstrings` والتعليقات والتوثيق لضمان فهم الوكيل للسياق.
- عند إضافة مفهوم جديد، يجب تحديث هذا المعجم أولاً.

## 6. توصيات تحسين المسميات (Nomenclature Recommendations)

لتفادي الالتباس المستقبلي بين المعاني العامة والخاصة، نوصي بتعديل المسميات التالية:

| المسمى الحالي | المسمى المقترح | سبب التغيير |
| :--- | :--- | :--- |
| `core/` (في الجذر) | `runtime/` أو `launcher/` | لتمييزه عن الحزمة المكتبية `src/mithaly/core`. حالياً كلمة `core` مكررة في مكانين بمسؤوليات مختلفة. |
| `Raw_Artifact/` | `legacy-archive/` | كلمة `Artifact` في Mithaly تعني مخرجاً حالياً ذا قيمة. `Raw_Artifact` يوحي بشيء خام بينما هو في الواقع "مقبرة" للمشاريع القديمة. |
| `System Architecture Gap.txt` | `architecture_gap.md` | إزالة المسافات في الاسم وتوحيد الامتداد إلى `.md` ليناسب نظام التوثيق والقراءة الآلية. |
| `docs/context/history.md` | `session_history.md` | لتمييز سجل الجلسة الحالي عن "تاريخ المشروع العام" (Project History). |
