# دليل إدارة وتوثيق Mithaly (Sovereign Docs Guide)
==================================================

هذا المجلد هو **مركز الإدارة والحوكمة (Control Center)** لمشروع Mithaly. يُستخدم لإدارة دورة حياة النظام، تتبع المهام، وترسيخ المعرفة.

## 1. فلسفة المجلد وهيكلية المراجع
بدلاً من تشتت القواعد، نعتمد على ثلاثة أعمدة سيادية:

- **الدستور الجَامع (`MITHALY_CONSTITUTION.md`):** مصدر الحقيقة الوحيد للقواعد والمصطلحات (في الجذر - جاري إعادة البناء).
- **سجل المهام (`docs/mithaly_todo.md`):** المحرك التنفيذي الذي يربط كل عمل بمرجع استباقي.
- **مركز المراجع (`docs/todo_references/`):** المستودع المركزي الذي يحتوي على كافة الأدلة التقنية، التقارير، والخطط المعتمدة.

## 2. تنظيم المجلدات الداخلية
- `docs/context/`: اللقطات اللحظية للسياق (`current_context.json`) والوعي التشغيلي.
- `docs/knowledge/`: الذاكرة الدائمة والسياسات المعتمدة (patterns, policies).
- `docs/architecture/`: المخططات الهندسية وسير العمل التقني (`workflow.md`).
- `docs/todo_references/`: النسخ المحلية الموثوقة للأدلة والتقارير المرتبطة بالمهام.

## 3. قواعد قداسة النصوص (Document Sanctity)
تخضع الوثائق الأساسية (الدستور، سير العمل، وهذا الدليل) لحماية مشددة:
- يُحظر التعديل الآلي بواسطة الوكيل دون إذن صريح ويدوي من المستخدم.
- أي محاولة تجاوز ستؤدي لتفعيل `INFLECTION_POINT` فوراً.

## 4. كيفية العمل مع المهام
عند البدء بمهمة من `mithaly_todo.md`:
1. ابحث عن وسم `(المرجع: docs/todo_references/filename)` بجانب المهمة.
2. اقرأ الملف المرجعي داخل مجلد المراجع لفهم المنطق التقني المتفق عليه.
3. التزم بالمنهجية الموصوفة لمنع الانحراف المعماري.
