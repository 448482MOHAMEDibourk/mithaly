دور مجلد docs
=================

هذا المجلد مُخصَّص للاستخدام الإداري والمؤقت داخل مشروع Mithaly. يُستخدم لتخزين:

- لقطات سياق التشغيل: `docs/context/` (مثل `current_context.json`, `history.md`, `analysis_tickets.json`).
- مسودات قاعدة المعرفة ومجلد السياسات: `docs/knowledge/` (مسودات، سياسات مؤقتة، واختبارات قبول).
- مواد توثيقية وإرشادية مرتبطة بالإدارة والحوكمة.

ملاحظات توجيهية للمطورين:

- لا تعتبر محتويات `docs/` مصدراً قابلاً للنشر للكود؛ الشيفرة المصدرية الحقيقية توجد تحت `src/mithaly`.
- `docs/` هو مساحة مؤقتة لإدارة التذاكر واللقطات ومسودات المعرفة قبل توثيقها أو نقلها إلى مستودع المعرفة الدائم.
- لا تعتمد عمليات التشغيل المباشر أو الاستيراد من `docs/` في بيئات الإنتاج.

سير العمل الموصى به:

1. توليد تذكرة تحليل أو لقطة سياق تذهب إلى `docs/context/` تلقائياً.
2. إجراء التحليلات والمراجعات عبر الطبقات المسجَّلة أو واجهة الإدارة.
3. بعد قبول سجل ما (وسمه بـ `trusted: True`)، يتم حفظه نهائياً عبر `FeedbackLoop.persist_to_kb()` إلى `docs/knowledge/kb.json`.

بهذه الطريقة، يفصل المشروع بوضوح بين التخزين المؤقت الإداري ونسخ المعرفة الموثوقة.
Mithaly — Documentation Index
=============================

ملف مرجعي سريع لمشروع Mithaly.

- الدستور المعماري: `docs/MITHALY_CONSTITUTION.md`
- معجم المصطلحات: `docs/TERMINOLOGY.md`
- مرجع المعرفة (أنماط/سياسات/أمثلة): `docs/knowledge/`
- مهام المشروع: `docs/mithaly_todo.md`
- محرك التشغيل (runner): `core/engine.py` (رابط إلى المحرك داخل الحزمة: `src/mithaly/core/engine.py`)

سلوكيات مهمة:
- حافظ على `src/mithaly` كمصدر الحقيقة للكود.
- ضع القوالب والأدوات ضمن `project-generator/` أو `tools/` وليس في الجذر مباشرةً.

قاعدة تنظيم الملفات (ملخص):

- لا تُنشئ ملفين يؤدّيان نفس الوظيفة داخل المستودع ما لم يختلف نطاق كل ملف بوضوح. عند وجود اختلاف مقصود، أضف تعليق رأس (header comment) يوضّح المسؤولية والحدود (مثال موجز: "هذا الملف مسؤول عن التهيئة والتكوين فقط؛ تنفيذ الخطوات يتم في `executor.py`").


للبدء سريعًا (انظر أيضاً `docs/USAGE.md`).
