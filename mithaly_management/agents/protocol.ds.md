## 🔒 **قواعد التنفيذ الصارمة**

### القاعدة 1: مبدأ عدم التكرار
**امنع الازدواجية قبل الإنشاء:**

```bash
# العملية الإلزامية قبل إنشاء أي ملف جديد
1. تحديد الكلمات المفتاحية للملف المطلوب
2. البحث في المشروع بأكمله:
   find . -type f -name "*كلمة_مفتاحية*" 2>/dev/null
3. البحث في المجلدات الشائعة:
   - scripts/           (للنصوص البرمجية)
   - tools/             (للأدوات المساعدة)
   - mithaly_management/ (لإدارة المشروع)
   - knowledge/         (للمعرفة المخزنة)
4. إذا وجد ملف مشابه:
   - قيم ما إذا كان يمكن تعديله بدلاً من إنشاء جديد
   - تحقق من تاريخ التعديل الأخير
   - اسأل: "هل هذا يلبي 80% من الاحتياج؟"
```

### القاعدة 3: هندسة الملفات والحفظ
**هيكل ذكي مع حفظ التاريخ:**

```
قاعدة "وظيفة واحدة لكل مجلد":
- كل مجلد رئيسي يجب أن يكون له غرض واحد واضح
- تجنب المجلدات "العامة" مثل misc/ أو temp/
- استخدم تسميات واضحة تعكس المحتوى

قاعدة "الأرشفة قبل الإزالة":
عند استبدال ملف رئيسي:
1. أنشئ نسخة أرشيفية في: mithaly_management/archive/YYYY-MM-DD/
2. احتفظ بالملف القديم لمدة 7 أيام على الأقل
3. أضف تعليق في الملف الجديد يشير إلى الملف السابق

مثال عملي:
# بدلاً من حذف config_old.py
mv config_old.py mithaly_management/archive/$(date +%Y-%m-%d)/
echo "# تم استبدال config_old.py في $(date)" >> config_new.py
```

## 🎨 **الإبداع والمرونة في التنفيذ**

### المساحة الإبداعية المسموحة
**بينما القواعد صارمة، لديك حرية كاملة في:**

1. **إعادة الهيكلة الذكية**
   ```python
   # بدلاً من:
   # 10 دوال متشابهة مع اختلافات طفيفة
   
   # يمكنك:
   # إنشاء دالة عامة مع معاملات
   def process_data(source, transformer, output_format):
       # كود أنيق وقابل لإعادة الاستخدام
       pass
   ```

2. **اقتراح أنماط معمارية جديدة**
   - إذا لاحظت نمط مشاكل متكرر
   - إذا كان الحل الحالي غير قابل للاستمرار
   - إذا وجدت فرصة لتبسيط كبير

3. **ابتكار أدوات جديدة** (بعد التحقق)
   ```
   العملية:
   1. حدد المشكلة بوضوح
   2. ابحث عن حل موجود (القاعدة 1)
   3. إذا لم يوجد، صمم الأداة الجديدة بحيث:
      - تحل المشكلة الحالية
      - تكون قابلة لإعادة الاستخدام
      - موثقة جيداً
      - متوافقة مع النظام الحالي
   ```

### مبادئ التصميم المرن
- **مبدأ الـ 80/20**: حل 80% من المشكلة أولاً
- **التدرج في التعقيد**: ابدأ بسيطاً ثم تطور
- **التوثيق مع التنفيذ**: لا تؤجل التوثيق
- **التوافق مع الماضي**: احترم القرارات السابقة ما لم تكن خاطئة بوضوح

## 🎯 **الخلاصة: التوازن بين الصرامة والمرونة**

القواعد موجودة لخدمتك، لا لعقلك.
